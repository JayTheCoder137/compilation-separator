# Compilation Separator

Teilt Bild-Compilations in einzelne originale Bilddateien.

## Funktionen

- Zerlegen von Collagen in Einzelbilder
- Erhalt der Originalpixel durch Zuschneiden
- Export als PNG
- Erstellung eines ZIP-Archivs
- Unterstützung für Raster und individuelle Ausschnitte

## Datenschutz

Compilation Separator speichert oder verarbeitet keine Bilder auf externen Servern.
